# lumi 三言笔记 · 安装包分发仓

本仓**只放安装包（Releases 附件），不放源码**。源码在私有仓 `rockdork/lumi-note`。

## 下载

- **macOS（Apple Silicon）**：`LumiNote-<版本>-aarch64.dmg`
- **Android**：`LumiNote-<版本>.apk`

最新版本见 [Releases](https://github.com/rockdork/lumi-note-releases/releases)。

## 说明

- 应用内「检查更新」直连本仓 Releases（Gitee 国内直链更快）。
- 本仓由发布脚本（`scripts/publish-release.mjs`）自动维护，**请勿向本仓提交代码或 Issue**。
- 各产品对应源码仓：rockdork/lumi-note（私有）。
